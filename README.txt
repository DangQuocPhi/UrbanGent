UrbanGent - Responsive Men Fashion Website
===========================================

Purpose
-------
UrbanGent is a branded, responsive, multi-page fashion shopping prototype for
Unit 13: Website Design & Development. It uses HTML5, CSS3, JavaScript and
Bootstrap 5.3.3, matching the P6 implementation requirements in Assignment
Brief Part 2.

Required pages
--------------
1. index.html    - Home, product categories, search/filter and product cards
2. contact.html  - Contact form with JavaScript validation
3. login.html    - Login form with JavaScript validation
4. register.html - Registration form with JavaScript validation
5. profile.html  - Customer details, loyalty status and recent orders
6. cart.html     - Shopping cart with localStorage, quantity and totals

Implemented assignment criteria
-------------------------------
- Branded and visually consistent multi-page interface
- Semantic HTML5 structure and realistic fashion content
- Bootstrap responsive grid and mobile navigation
- Custom CSS design system and mobile breakpoints
- JavaScript validation for login and registration forms
- Clear validation feedback, required fields and password visibility controls
- Functional cart: add, remove, change quantity and save between page visits
- Product category filters and keyword search
- Local product images with meaningful alternative text
- SEO descriptions, accessible labels, skip links and keyboard focus support
- Vietnamese currency and realistic delivery/returns content

How to run
----------
Open index.html in a browser. An internet connection is required for the
Bootstrap CDN. Product images are stored locally in the images folder.
